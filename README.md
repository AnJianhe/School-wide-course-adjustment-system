# 全校调课系统

Flask + SQLite 后端，包含管理员、教师、班级大屏三种角色。所有页面从同一个后端打开，多台电脑共享服务器上的数据库。

## 20 种界面语言

支持简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、俄语、阿拉伯语、印地语、意大利语、荷兰语、土耳其语、越南语、泰语、印尼语、马来语和波兰语。首次打开按浏览器 `Accept-Language` 偏好及权重自动匹配；不支持的语言回退简体中文。页面顶部可手动选择，并通过 Cookie 记住一年，退出登录后仍保留。

语言覆盖登录、账号管理、改密、课表、申请列表、操作结果与错误提示；日期时间使用对应地区格式。阿拉伯语使用从右向左布局。账号、用户填写的调课原因、自定义课程名和数据库字段保持原值。内置课程名称和时间段只在显示时翻译。

语言包保存在 `locales/*.json`，运行时从本地读取，不调用在线翻译服务。非简体中文语言包使用机器翻译生成；正式对外使用前可由母语使用者校对教学术语。新增或修改界面文案时同步更新 20 份语言包。

## 启动（Python 3.11 或以上）

Windows PowerShell，在项目目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\.venv\Scripts\python.exe -m flask --app app create-admin
.\.venv\Scripts\python.exe app.py
```

`create-admin` 交互输入管理员账号、密码和确认密码，输入的密码不回显。密码为 10～128 个字符，建议每个账号使用不同密码。系统不提供统一默认密码。启动后访问 <http://127.0.0.1:5000>；以后可双击 `start.bat` 启动。

Linux/macOS 使用 `.venv/bin/python` 代替上述 Python 路径。应用通过 Waitress 启动，默认不开启调试模式。

## 管理员配置

1. 使用创建的管理员账号登录。
2. 在“系统管理”创建教师账号（例如 `qfc01`）和班级账号（例如 `101`），设置各自的初始密码。旧账号显示“未配置”时，也在此设置密码。
3. 在“课表配置”选择班级、教师、课程名称和时间段，新增或编辑基础课表。系统拒绝班级或教师的同时间段冲突。
4. 用户第一次登录，或管理员重置密码后，须修改初始密码。账号停用、改密或重置密码后，旧会话失效。
5. 教师登录后提交调课申请，接课教师登录后批准或拒绝。管理员可查看全校调课记录。班级账号登录后仅查看本班课表，页面每 30 秒刷新。

管理员不能停用或降级自己及最后一个有效管理员。账号名不可修改；已关联课表或申请的账号不能变更角色。已关联调课记录的课程不能修改或删除，避免破坏历史记录。

忘记密码时，在服务器项目目录执行下列命令，按提示输入新密码：

```powershell
.\.venv\Scripts\python.exe -m flask --app app reset-password --username admin
```

## 现有数据升级

运行数据默认存储在 `instance/school.db`。首次启动时，如项目根目录存在旧 `school.db`，会复制到该路径，保留原件。旧数据库只添加认证字段和调课原因字段，不覆盖已有用户、课程和申请；修改表结构前保存 `*.pre-auth.bak` 备份。旧账号没有密码，管理员为其配置密码后才能登录。

升级前停止旧服务并备份完整数据库。如果旧数据库文件名不同，可在 `.env` 中配置 `DATABASE_URI=sqlite:///原文件名.db`；相对路径放在 `instance/`，首次迁移也会检查项目根目录同名旧库。绝对地址示例：`sqlite:///H:/学校与电教/电教项目/调课系统/school.db`。

仓库不再跟踪真实 `.env`、数据库、备份、日志和 Python 缓存；旧 Git 历史仍可能包含它们。旧公开会话密钥应更换。`SECRET_KEY` 留空时生成随机密钥，保存到 `instance/secret.key`；保留该文件可在重启后继续使用会话。手动配置密钥至少 32 个字符。

全新安装默认不生成演示课表。需要原有六个年级的示例时，在无业务数据的数据库上显式执行：

```powershell
.\.venv\Scripts\python.exe -m flask --app app seed-demo
```

该命令创建 36 个教师账号、30 个班级账号和 120 条课表。演示账号仍需管理员配置密码。

## 校园内网配置

在 `.env` 设置 `HOST=0.0.0.0`、`PORT=5000`，启动后其他电脑访问 `http://服务器内网IP:5000`，并在服务器防火墙允许该端口。所有客户端使用同一个服务器，不要为每台电脑分别启动独立数据库。HTTPS 部署时设置 `COOKIE_SECURE=1`；HTTP 内网访问保持 `0`。不接受外站跨域请求。

运行文件包含账号及业务数据。停服后备份整个 `instance/` 目录，并妥善保管 `.env`；恢复时放回同一路径。

## 调课规则与范围

沿用原项目四个固定时间段：上午1、上午2、下午1、下午2。当前“调课”是将某节课程转交给接课教师，批准后持续生效，不交换两节课，也没有日期、星期、学期和到期恢复规则。再次转交由当前接课教师发起。申请和批准时均校验时间冲突；同一课程只允许一个待处理申请；SQLite 写操作串行，防止同时批准造成重复占课。审批人必须为目标教师。

## 验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

回归测试覆盖会话隔离、密码校验、CSRF、登录失败限制、角色权限、密码重置与停用、改密、课表配置、申请/批准/拒绝、大屏返回数据、重复申请与并发冲突、重启持久化、旧库备份和重复迁移。GitHub Actions 使用 Python 3.11、3.12 运行同一测试。
